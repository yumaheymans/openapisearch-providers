This is a personal fork of the OpenAPI Search [providers.json](providers.json). You can fork/edit this collection and use it as your main search results for your own https://openapisearch.com landingpage.

When logged in, it will automatically pull these providers rather than the default ones.

Feel free to send PRs to the original at https://github.com/janwilmake/openapisearch-providers as well, but only with high-quality production-grade APIs. If you want to search through your own creations, put them in your personal collection.
